Application Description
The Smart Pantry Manager application will be built using JAVA ,with the use of Android Studio ,it will support full CRUD operations - Create,Read,Update and Delete ,of the pantry items.

Database
The database of choice for this application will be SQLite,as it is a lightweight , will store data directly to the device ,supporting offline storage.

The set up instructions
Open the Smart Pantry Manager in Android Studio.
Run the app on an emulator or physical device.
On first run, the app will automatically do the recipes into the database.
Features 
Add Item -saves inputs to pantry 
PantryList-Displays and stores all items in RecyclerView
Suggested Recipes- provides recipes based on available of ingredients in the pantry
Recipe details - available recipes with short steps 
Settings- customize themes and alerts
